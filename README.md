# Color Reflex

A one-tap mobile reflex game. The ball falls continuously and can only be red or blue — tap to switch its color, and only cross barriers that match. Includes four difficulty levels (Easy, Normal, Hard, Insane).

Built as a single self-contained `index.html` (no build step, no dependencies) — open it directly in a browser, or serve the folder with any static file server.

## Run locally

Open `index.html` in a browser, or serve it:

```bash
npx serve .
```

## Deploy

This is a plain static site, so it works as-is on GitHub Pages, Netlify, Vercel, or any static host — just point the host at `index.html`.
